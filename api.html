API

Episto's data is a set of static files: no key, no account, no limit, and nothing about what you look up reaches us. Version 1 is described in data/api.json; a later format gets a new version and v1 stays as documented here.

For meta-research and machine learning

The register is also published as tables for bulk use, free for any purpose under CC0, machine learning included: data/meta/, listed under meta in api.json. It holds counts by type, field and year, every decided round, the dependencies between papers, and the flags' logic trees (logic.jsonl): each argument's claims, the load-bearing claim, the failure and what follows, with the tree written as one line of logic. The files carry no personal data, and a new set comes with every monthly build.

Every flagged paper at once

Download flagged-2026-10.csv.gz (gzip-compressed CSV, released monthly; the columns are on the download page). Checking your own lists against it keeps them on your computer.

curl -O https://episto-org.github.io/flagged-2026-10.csv.gz
gunzip flagged-2026-10.csv.gz

One paper by DOI

Each paper's record sits in data/papers/<xx>.json, where xx is the first byte, in hex, of the 32-bit FNV-1a hash of its id, doi: followed by the lower-case DOI.

function shardOf(id) {
  let h = 0x811c9dc5;
  for (const b of new TextEncoder().encode(id)) {
    h ^= b;
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return (h >>> 24).toString(16).padStart(2, '0');
}
const id = 'doi:' + doi.toLowerCase();
const shard = await (await fetch('https://episto-org.github.io/data/papers/' + shardOf(id) + '.json')).json();
const paper = shard[id] ?? null;   // null: not flagged

A whole reference list

Libraries and journals can check a reference list from the command line with the same matching as the checker (DOIs, then titles):

node tools/check-list.mjs references.txt --data https://episto-org.github.io/data --out results.csv

The script is in Episto's code, Apache-2.0. Published data is CC0: use it for anything, with no permission needed.

Episto flags specific problems with specific research, decided by randomly drawn panels of pseudonymous reviewers. Flags are not judgements of people.
