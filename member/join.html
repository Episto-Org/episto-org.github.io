Join

Membership is by invitation. This page writes your entry for the members list. It asks for no name, email, address or phone number, and nothing you type leaves your browser.

3. Your recovery code

Write this down on paper now and keep it apart from your password. If you lose your password, this code and your pseudonym let you set a new one yourself. It is shown only once and is not in the reply below.

Sign in to GitHub with the account you gave above, then press the button. It opens a request on GitHub with everything sealed so only the steward can read it; press Create there. The steward checks your invitation by rule and admits you within the hour. Nobody approves it by hand.
