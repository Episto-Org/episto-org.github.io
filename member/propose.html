Opening a new round on an existing flag

  
Disputes, re-proposals, authors' responses and outside events change the existing flag file: add a request block and append new evidence entries with the next round number. Nothing else in the file may change. Example:


request:
  trigger: dispute          # or reproposal, author-response, outside-event
  by: your-pseudonym        # leave out when logins are sealed
  argument: What the new evidence shows and why it changes the outcome.
  # outside_event: { kind: replication, url: https://... }   (outside-event only)
evidence:
  # ...existing entries unchanged...
  - item: 1
    round: 2
    text: The new evidence.
    urls: [https://example.org/new-evidence]









Episto flags specific problems with specific research, decided by randomly drawn panels of pseudonymous reviewers. Flags are not judgements of people.
